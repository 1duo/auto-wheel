# Selected native execution output

`causalbook.ReduceSelectedIntervals` emits requested native instrument IDs for each one-second-or-shorter window. It delegates state reduction and complete-source validation to the unchanged `ReduceIntervals` implementation. Every source record remains subject to identity, ordering, structural, EOF and digest checks, including records for unselected instruments and records outside the requested windows. Switching a mask does not reset a book or refresh its clocks.

The caller supplies the full independently attested instrument universe and a `SelectedWindow` plan. Masks must be nonempty, unique subsets of that universe. They are copied and sorted before any source read; callbacks cannot change later masks or accepted accounting. A 4,194,304-observation bound limits copied masks to 16 MiB of raw IDs. This is a memory bound, separate from portfolio limits. The returned native summary covers the complete original source, while the observation count covers selected output. Any failure returns a zero summary; emitted callbacks remain provisional until all inner and outer checks succeed.

The research helper in `research/simulation/2026-10-05/cycle58-selected-execution-reference` accepts an owner-only regular descriptor file and a new owner-only staging FD. Its descriptor uses `selected_windows` entries with `Window` and `Instruments`, alongside the existing expected native evidence, complete scope, maximum age and dated mappings. It rejects descriptor symlinks. It retains the accepted original vector and observation codecs and emits `AutoWheelSelectedNativeExecutionIntervalV1`. Its report explicitly leaves causal selection, continuous pending-order coverage, source qualification and historical performance unqualified.

Focused local checks cover switching into an earlier-updated contract, quiet aging across a selection gap, equal-time bid/size losses at the closed boundary, invalid masks before input consumption, complete validation of unselected later records, late digest/trailing/callback/cancellation failures, callback mutation, private staging, symlink rejection and output digest/count checks. They ran on Go 1.27.1 with module language version 1.26 and Go 1.26.8 guideline selection. They are synthetic checks, not historical data qualification. Linux Go 1.26.8 compilation and real-native Go/Python comparison remain required when MSI access returns.

Integration must bind each mask to the frozen strategy's causal decision evidence and preserve every required interval until a verified fill or GFD expiry. Reusing a raw source interval across independent mode studies is valid only with separate decision and portfolio state. An omitted instrument/window supplies no coverage. The outer harness still owns acquisition receipts, original metadata and mapping validation, decoder/decompressor EOF, compressed and native hashes, descriptor and source stability, independent reconstruction and publication. Contract terms, tradability, Greeks and lifecycle evidence remain separate requirements.

Projection reduces derived output volume. Original licensed archives still require their full storage allocation and retention. All frozen 15 symbols, 126 sessions, 9,324 decisions, 126 closing valuations and independent mode studies remain in scope. The new helper makes no provider, financial-journal or production-trading calls.
